a.k.a. Single-Writer-Multiple-Reader

[[cache coherence|缓存一致性]]协议的一种不变式，CPU所使用的常见协议都具有该性质。

> Their defining characteristic is that a write to a memory location eagerly invalidates all other cached copies, ensuring there is only ever one writer; there can, however, be multiple readers that can concurrently read cached locations.
