## 平衡饮食

| **食物**         | **推荐摄入量**  |
| ---------------- | --------------- |
| **盐**           | < 5克           |
| **油**           | 25~30克         |
| **奶及奶制品**   | 300~500克       |
| **大豆及坚果类** | 25~35克         |
| **动物性食物**   | 120~200克       |
| —— 水产品        | 每周至少2次     |
| —— 鸡蛋          | 每天一个        |
| **蔬菜类**       | 300~500克       |
| **水果类**       | 200~350克       |
| **谷类**         | 200~300克       |
| —— 全谷物和杂豆  | 50~150克        |
| **薯类**         | 50~100克        |
| **水**           | 1 500~1 700毫升 |
